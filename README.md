# 박윤정 · YUNIE coach — 브랜딩 페이지

브레인 · 마인드 · 웰니스 통합코치 **박윤정(YUNIE)** 의 퍼스널 브랜딩 랜딩 페이지입니다.

빌드 도구도, 서버도, 설치 과정도 없는 **순수 정적 페이지**라 Vercel · GitHub Pages · Netlify 어디에 올려도 그대로 동작합니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 전체 (HTML · CSS · JS 한 파일) |
| `assets/yuni-portrait.webp` | 히어로 영역 프로필 사진 |

## 섹션

1. **Hero** — 핵심 메시지와 문의 CTA
2. **About** — 색채심리(CPA) · 뇌과학 · 아로마 세 축
3. **Philosophy** — "선수이기 이전에, 한 사람으로 성장하도록 돕는다" (LTAD · SDT · 빙산 모델)
4. **Lecture** — 시민강좌 · 워크숍 추천 주제 5가지
5. **Credentials** — 분야별 자격 및 인증
6. **Work** — YUNIE coach, NeuroCPA 통합 리포트, 무가치함의 심리학 강의 등
7. **Story** — 주얼리 디자인에서 멘탈 코칭까지의 연혁
8. **Contact** — Threads · Instagram · 블로그

## 수정하기

`index.html` 한 파일만 열어 고치면 됩니다.

- 색상 — 파일 상단 `:root` 의 CSS 변수 (`--coral`, `--bg`, `--moss` 등)
- 문구 — 각 `<section>` 안의 텍스트
- 사진 — `assets/yuni-portrait.webp` 를 같은 이름으로 교체

## 배포

Vercel에서 이 저장소를 Import 하면 프레임워크 감지는 **Other**, 빌드 명령 없이 그대로 배포됩니다.
